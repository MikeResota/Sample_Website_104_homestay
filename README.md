# Serenity Homestay & Bakery – Sample Website

A professional, fully responsive multi-page website built with **Bootstrap 5**, **HTML5**, **CSS3**, and **jQuery**.

## Features

### Design & UX
- Modern, warm, professional design with custom color palette
- Fully responsive (mobile, tablet, desktop)
- Smooth scroll animations and fade-in effects
- Hover animations on cards, buttons, and gallery
- Sticky navbar with scroll effects
- Back-to-top button
- Toast notifications for user feedback
- Sample Website We Create badge on homepage

### Pages
1. **Home (index.html)** – Hero with background image, features, stats counters, featured rooms, bakery preview with live Add to Cart, testimonials, newsletter
2. **About** – Story, values, bakery intro, FAQ accordion
3. **Rooms** – 4 detailed room cards with amenities + booking modal form
4. **Bakery** – Full product catalog with search, category filters, and working Add to Cart on every item
5. **Gallery** – Image grid with lightbox modal on click
6. **Contact** – Contact info cards, working contact form, map placeholder
7. **Cart** – Fully functional cart (view items, change quantities, remove, clear, totals with tax & shipping)
8. **Checkout** – Order form + order summary; places order, clears cart, shows success message

### Cart System (Client-side)
- Powered by localStorage
- Add / increase quantity / decrease / remove
- Live cart count badge in navbar on every page
- Subtotal, shipping (free over $50), tax (8%), grand total
- Persistent across page reloads
- Works offline after first load (CDN assets need internet)

### Other Functional Features
- Product search & category filtering
- Booking request form (modal)
- Contact form with simulated submit
- Newsletter subscription
- Animated number counters
- Date inputs restricted to today onward
- Active nav highlighting

## Tech Stack
- Bootstrap 5.3
- jQuery 3.7
- Bootstrap Icons
- Google Fonts (Playfair Display + Poppins)
- Vanilla CSS custom properties & animations
- localStorage for cart

## How to Use
1. Unzip the folder
2. Open `index.html` in any modern browser
3. Browse the Bakery, add items to cart, open Cart, change quantities, proceed to Checkout

## Notes
- This is a **demo / sample website**. Forms do not send real emails or process real payments.
- Images are high-quality Unsplash photos downloaded locally so there are no broken images.
- All paths are relative – the site works when opened directly or served from any static host.
