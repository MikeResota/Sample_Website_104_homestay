# Serenity Homestay – Sample Website

A professional, fully responsive multi-page **Homestay** website built with **Bootstrap 5**, **HTML5**, **CSS3**, **jQuery**, and **AOS** animations.

## Features

### Design & UX
- Modern, warm, professional design with custom color palette
- Fully responsive (mobile, tablet, desktop)
- Smooth scroll animations powered by AOS (Animate On Scroll)
- Hover animations on cards, buttons, and gallery
- Sticky navbar with scroll effects
- Back-to-top button
- Toast notifications for user feedback
- Sample Website badge on homepage

### Pages
1. **Home (index.html)** – Hero with background image, features, stats counters, featured rooms, amenities, experiences, testimonials, newsletter
2. **About** – Story, values, FAQ accordion
3. **Rooms** – 4 detailed room cards with amenities + booking modal form
4. **Gallery** – Image grid with lightbox modal on click
5. **Contact** – Contact info cards, working contact form, map placeholder

### Functional Features
- Animated number counters
- Booking request form (modal) with date restrictions
- Contact form with simulated submit
- Newsletter subscription
- Gallery lightbox
- Active nav highlighting
- Date inputs restricted to today onward

## Tech Stack
- Bootstrap 5.3
- jQuery 3.7
- Bootstrap Icons
- AOS (Animate On Scroll)
- Google Fonts (Playfair Display + Poppins)
- Vanilla CSS custom properties & animations

## How to Use
1. Unzip the folder
2. Open `index.html` in any modern browser
3. Browse rooms, view the gallery, and try the booking / contact forms

## Notes
- This is a **demo / sample website**. Forms do not send real emails or process real bookings.
- Images are high-quality photos downloaded locally so there are no broken images.
- All paths are relative – the site works when opened directly or served from any static host.
- Bakery and shopping cart features have been removed; this is a pure Homestay website.
